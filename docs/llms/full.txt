# externs-phpparser

> Kotlin/JVM adapter that parses PHP source files into AST text.

## Instructions for Agents

- Construct `BinPhpParser` and assign an absolute `target` before `execute()`.
- Configure `dumpType` and the parser flags for the requested output.
- Use `executeWith` for scoped target, dump type and flag overrides.
- Check the exit code and the expected output payload before decoding.
- Never reuse a cached command after changing the target file in place.

# Parser API

> External PHP binary management and AST parsing via nikic/PHP-Parser v5.7.0.

## Quick Start

```kotlin
import edu.jhu.cobra.externs.phpparser.BinPhpParser
import java.io.File
val parser = BinPhpParser().apply {
    dumpType = BinPhpParser.DumpType.JSON
    doResolveName = true
}
parser.target = File("example.php").absoluteFile
val result = parser.execute()
println(result.code)
```

## API

### BinPhpParser

**`BinPhpParser(phpBinary: File? = null, parserBinary: File? = null)`** — Construct parser. Resolves PHP binary (bundled ZIP > system PATH) and publishes the bundled dump script `php_parse.php`. Pass explicit binaries to override; `parserBinary` must be a php-parser PHAR. Raises `ExternalBinaryNotFoundException` if no PHP found; raises `ExternalBinaryInvalidException` if `phpBinary` is below PHP 7.4.

**`target: File`** — PHP source file to parse. Required. Raises `ExternalBinaryArgumentMissException` if unset at `execute()`.

**`dumpType: DumpType`** — Output format. Values: `S_EXPR` (default), `VAR`, `JSON`. `DumpType.opt` holds the CLI flag.

**`doPrettyPrint: Boolean`** — Enable `--pretty-print`. Default `false`.

**`doResolveName: Boolean`** — Enable `--resolve-names`. Default `false`.

**`doWithColInfo: Boolean`** — Enable `--with-column-info`. Default `false`.

**`doWithPositions: Boolean`** — Enable `--with-positions`. Default `false`.

**`doWithRecovery: Boolean`** — Enable `--with-recovery`. Default `false`.

**`executeWith(tmpConfig: BinPhpParser.() -> Unit): BinaryResult`** — Execute with temporary config. Restores `target`, `dumpType` and the five flags afterward; `workTmpDir` and `doCacheOutput` assigned inside persist.

### AbcBinary (superclass)

**`execute(): BinaryResult`** — Run the external binary. Returns cached result if `doCacheOutput` is `true` and cache hit. Returns code `-1` after the fixed 1-minute timeout; the timeout is not configurable.

**`doCacheOutput: Boolean`** — Cache output by command content hash. Default `false`.

**`workTmpDir: Path`** — Working directory for output and cache files. Default `{java.io.tmpdir}/cobra/binaries/BinPhpParser`.

### BinaryResult

**`BinaryResult(code: Int, output: File)`** — Execution outcome.

- `code`: `0` = success, `-1` = timeout, other values = process exit code.
- `output`: `File` containing stdout+stderr.

### Top-Level Functions

**`searchBin(name: String): File?`** — Search system PATH for executable. Returns first match or `null`.

**`searchBin(under: Path, vararg possibleNames: String): File?`** — Look up an executable as a direct child of a directory.

**`isPhpVersionValid(binary: File, minRequired: String, includeEqual: Boolean = true): Boolean`** — Check PHP version. Raises `ExternalBinaryInvalidException` on invalid format or unrunnable binary.

**`extractFileFromZip(zipInputStream: InputStream, toOutPath: Path, vararg fromZipPath: Path): Unit`** — Extract one ZIP entry to `toOutPath` atomically. Raises `ExternalBinaryNotFoundException` when no entry matches.

**`Path.crc32ChecksumString: String?`**, **`File.crc32ChecksumString: String?`** — CRC32 of a regular file as 8 lowercase hex chars; `null` when absent.

### Exceptions

**`ExternalBinaryNotFoundException(name: String, under: String? = null)`** — Binary not found. Raised during construction.

**`ExternalBinaryInvalidException(name: String, reason: String? = null, cause: Throwable? = null)`** — Binary exists but fails validation.

**`ExternalBinaryArgumentMissException(argName: String)`** — Required argument (`target`) not set.

## Configuration

| Option | Property | CLI Flag | Effect |
|--------|----------|----------|--------|
| Dump S-expr | `DumpType.S_EXPR` | `--dump` | Human-readable indented dump (default) |
| JSON dump | `DumpType.JSON` | `--json-dump` | Compact JSON array of Stmt nodes with `nodeType` + `attributes` + subnodes, no nesting depth limit; bytes that are not valid UTF-8 become U+FFFD, offsets index the unchanged file |
| Dump var | `DumpType.VAR` | `--var-dump` | PHP `var_dump()` output for exact structure inspection |
| Pretty print | `doPrettyPrint` | `--pretty-print` | Regenerate PHP source from AST (round-trip test) |
| Name resolution | `doResolveName` | `--resolve-names` | Apply `NameResolver` visitor — resolves use/alias/namespace names to FQN |
| Column info | `doWithColInfo` | `--with-column-info` | Add column numbers to error messages |
| Positions | `doWithPositions` | `--with-positions` | Add `startFilePos`/`endFilePos` to node dumps |
| Recovery | `doWithRecovery` | `--with-recovery` | Parse broken PHP — inserts `Expr_Error` placeholder nodes |

- Construction extracts resources under the initial `workTmpDir`; assigning the property afterward changes output and cache placement, not resolved binary paths.
- System property `java.io.tmpdir` sets the default `workTmpDir` root.
- Environment variable `PATH` is searched for `php` when no bundled build matches the host.

## Gotchas

- Construction resolves binaries eagerly. Fails fast if no PHP available.
- `executeWith { }` restores target, dump type and five flags on every exit; changes to `workTmpDir` and `doCacheOutput` persist.
- Output caching keys on the command, not file content. Changing file content without changing its path does not invalidate the cache.
- Only code `0` results are cached; recovery can exit `0` with diagnostics and no AST, so validate the expected payload before decoding.
- Bundled PHP: macOS x86_64/aarch64, Linux x86_64/aarch64, Windows x86_64.
- `--resolve-names` does not resolve `self`/`parent`/`static` or unqualified function/constant names. Full resolution behavior: [php-parser-guide.md](php-parser-guide.md).
# Parser output usage

> Caller requirements for reading parser output and unresolved names.

## Quick Start

```kotlin
import edu.jhu.cobra.externs.phpparser.BinPhpParser
import java.io.File
val parser = BinPhpParser().apply {
    target = File("example.php").absoluteFile
    dumpType = BinPhpParser.DumpType.JSON
}
val result = parser.execute()
println(result.code)
println(result.output.readText())
```

## API

- `BinaryResult.code: Int` is the process exit code; `-1` indicates timeout.
- `BinaryResult.output: File` contains merged stdout and stderr, including diagnostics and operation headers before the payload.
- The [AST reference](../research/index.md) specifies node and subnode representations.

## Configuration

- Set `dumpType = BinPhpParser.DumpType.JSON` to request the [JSON dump](../glossary/glossary-dump.md#json-dump).
- Set `doResolveName = true` to apply PHP-Parser name resolution.
- Set `doWithRecovery = true` to collect parse diagnostics and request a partial AST.
- Leave `doPrettyPrint` false when expecting only an AST payload; enabling it emits PHP text before the requested dump.

## Gotchas

- Skip diagnostic and operation-header lines before decoding the expected payload; output is not a standalone JSON file.
- Recovery can exit `0` with no AST when the parser returns no statements; require a JSON payload before decoding.
- Name resolution leaves `self`, `parent`, `static`, and unqualified function/constant names for caller lookup. Unqualified functions/constants carry a namespace-prefixed `namespacedName` attribute.
- `Name.name` is one backslash-separated string. `Name_FullyQualified` represents resolved names; `Stmt_Namespace` and `Stmt_Use` remain in the output.
- Name resolution resolves namespace-relative names; it does not decide late static binding.
